## 1. 产品形态

| 项 | 要求 |
|---|---|
| 外形 | U 盘大小，目标约 20 × 55 mm（宽 18–22，长 50–60），一端公头、一端母座 |
| USB1 | USB-C **公头**，插主控机（Book）；整板唯一供电入口 |
| USB2 | USB-C **母座**，经数据线接被控机；只做数据和 VBUS 检测 |
| 无线 | 不带任何无线功能 |
| PCB | **双层铜、元件单面贴装**。不做单层铜板，理由见第 6 节 |
| EDA | 嘉立创 EDA 专业版；KiCad 仅作 DRC 交叉检查。打样、贴片走嘉立创 |

| 功能 | 候选 | 说明 |

## 3. 电气要求

### 3.1 供电与隔离（硬约束，详见供电要求文档）

- 仅 USB1 VBUS 给整板供电。USB2 VBUS 不进任何电源轨，不得反向送到 USB1。
- USB2 VBUS 仅经高阻、限流分压送 MCU GPIO 做连接检测；只在被控机 VBUS 有效时使能 USB2 设备上拉。
- 两口 VBUS 不直连；CC 各自按 Device（UFP）配置 5.1 kΩ 下拉，不跨口相连。保护器件、检测线、信号脚和调试口都不得形成回灌路径。
- 数据地共用，不做电气全隔离。
- 防残留电压：USB2 检测分压需保证拔线后快速放电（参考旧工程 `r2-b-vbus-bleed-review`）。
- USB 描述符的供电/电流声明须与实物一致。

### 3.2 USB 高速信号

- 两路 USB 2.0 HS（480 Mb/s），90 Ω 差分，下方完整地平面；差分线不换层、不跨分割，尽量短。
- ESD 器件紧靠连接器，走线经过 ESD 焊盘，不拉支线。
- 母座 D+/D− 两组并联的交叉在连接器下方用最短过孔完成，不用 0 Ω 跳线。
- 公头只有一组 D+/D−（A6/A7）。

### 3.3 MCU 外围

- 外置 Flash：当前固件原型用 SPI1：PA4 CS、PA5 SCK、PA6 MISO、PA7 MOSI。须确认 WEU6 封装可用；若引脚冲突，同步改固件。
- 调试/烧录：引出 2 线 SWD（SWDIO/SWCLK）+ GND + 3V3 测试焊盘，供 WCH-LinkE 使用。具体引脚以数据手册为准。
- 测试焊盘的 3V3 只用于产测受控供电，不能常态旁路 USB1 独供约束。
- 复位、BOOT 配置按原厂评估板；不加多余 LED、排针。可留一颗状态 LED（成本允许时）。

## 4. 机械与工艺

- 元件全部放顶面，一次标准型 SMT；公头焊区受力需外壳支撑，不能只靠 SMT 焊脚承受插拔力矩。
- 板厚按公头图纸焊接平面、壳体净空和外壳决定（TC-002 图中“沉板 0.95”是沉入深度，不是板厚）。
- 公头板边开口、拼板工艺边和支撑需与嘉立创确认。
- 导出 STEP 用于外壳设计。

## 6. 为什么不用单层铜板

1. 两路 HS 差分需要连续地平面做参考，单层无法控阻抗。
2. 母座 D+/D− 并联必须交叉，单层只能在高速路径上加跳线。
3. QFN68/LQFP100 在单层上扇出需大量跳线。
4. 嘉立创单层与双层打样差价很小；真正省钱的是单面贴装（少一次工程/钢网费）。

## 7. 设计流程与验收

1. 本规格书经用户审阅 → 画原理图（嘉立创 EDA）→ ERC。
2. 原理图审核：供电/回灌、CC、ESD、Flash、调试口。
3. 布局布线 → DRC（嘉立创 + KiCad 交叉）→ 导出 Gerber/BOM/CPL/STEP 并交叉核对。
4. 10 块打样；**下单前须用户确认**。
5. 实物验收按 [USB 供电与热插拔要求](USB_POWER_AND_HOTPLUG_REQUIREMENTS.md)：两种插入顺序、任一端单独拔插、正反插、只接 USB2 时 USB1 无输出；双 HS 稳定枚举；满载传文件时键鼠与边缘返回不受阻。

# USB 供电与热插拔要求

状态：2026-11-09 用户确认的 PCBA 约束补充；尚未设计 PCB、选定电源隔离器件或完成量产板验收。

## 接口与供电

- USB1 为主控侧 USB-C 公头，是整板唯一的正常供电入口。
- USB2 为被控侧 USB-C 母头，保留键鼠、控制和 Bulk 数据通信。USB2 的 5V 不得接入整板电源轨，也不得反向送到 USB1。
- USB2 的 VBUS 仅用于高阻、限流的连接检测。不得为阻断供电而取消 VBUS 检测；仅在被控机 VBUS 有效时使能该侧 USB 设备连接。
- USB1、USB2 的 VBUS 不得直连；两侧 CC 各自按 USB 设备角色处理，不能跨口相连。保护器件、检测线路、信号引脚和调试接口也不得形成替代回灌路径。
- USB2 仍需数据地参考；本要求是电源隔离，未要求切断 USB 数据地或实现电气全隔离。
- 产品调试供电不得常态旁路 USB1 独供约束。若保留生产测试供电，须有明确、受控的隔离方式；不能照搬现开发板 DBG 供电行为。
- USB 描述符的供电声明、电流声明及固件连接检测必须与实物一致。

## 用户可见行为

| 场景 | 必须达到的行为 |
| --- | --- |
| 先接 USB2→被控机 | 整板可保持未上电；不要求提前运行，但不得向主控侧送电或造成错误连接状态。 |
| 随后接 USB1→主控机 | 整板上电，两侧自动识别，主控程序自动连接；不用重新拔插 USB2、按 RESET 或手动开程序。 |
| 先接 USB1，再接 USB2 | 自动建立控制；不得依赖固定插入顺序。 |
| USB2 保持连接，单独拔插 USB1 | 断开时释放主控输入；接回后自动重新识别、启动控制并恢复边缘返回。 |
| USB1 保持连接，单独拔插 USB2 | 不应让整板掉电；主控本机输入正常，USB2 接回后自动恢复。 |
| 主控重启并登录，或控制程序退出后插入 | 在已有必要授权有效时自动启动并连接，不要求操作被控机。 |

## 验收

- 固定主控/被控角色，分别测试两个插入顺序、任一端独立拔插、USB-C 正反插及主控重启登录。每次记录 USB 枚举、程序启动和实际输入结果。
- 两端同时接电脑前，确认两侧 VBUS 隔离及无反向供电；仅 USB2 接入时，USB1 不得成为供电输出。最终测量方法与限值按所选器件和适用 USB 规范确定，不能只看电源灯。
- 全部场景验证键鼠、自动边缘返回和两台机器内部复制粘贴。对已实现的数据通道，在大文件负载下重测输入延迟、断线释放及恢复；不得将文件通道恢复当成键鼠恢复的前提。
- 主控仅在设备真实枚举、身份与角色核对通过后接管。失败状态必须可诊断，不能用不断复位整板掩盖电路问题。
- 当前开发板的接线恢复成功不等于上述验收完成。本文件不宣称目标端零组件剪贴板已实现。

量产候选仍为 CH32V407，开发测试板仍为 CH32V467；成本和功能约束保持现行要求。本补充不包含 PCB 布局或布线。

规范依据：[USB Type-C R2.0](https://www.usb.org/sites/default/files/USB%20Type-C%20Spec%20R2.0%20-%20August%202019_0.pdf)，4.5.2.2.8.2 描述 Source 附着前的 VBUS 与 CC 条件。该规范不证明现有 Petros 板存在回灌；实机经过另见 [自动启动与接线诊断](../docs/history/CONTROL_AUTOSTART_20261109.md)。

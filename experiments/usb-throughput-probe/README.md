# USB 内存测速候选

用于分开测量两侧 CDC/Bulk 收发和双向桥接。**尚未完成全链路实机验收**。
数据为已知的 `0xA5` 字节，不使用 Finder、磁盘文件或剪贴板。
结果仍包含 CDC 驱动、USB 调度、缓冲区和主机检查开销，不能称为芯片满速。

固件必须显式启用 `--bulk-probe`；默认版本不包含该入口。
每个方向使用独立、有界队列及私有 DMA 副本。先服务原键鼠和触点，
再处理文件端点；原 USB 描述符不变。只在正常协议单元边界识别测速命令，
文件正文中相同的字节不触发测速。命令校验失败时原样交回原解析器。
正文空闲超时为 5 秒，桥接两端初次会合最多等 60 秒。

两端先各做 64 MiB 本地收、发，再做两个方向的桥接。
目标端完整测试会先检查一次 512 字节回传，以区分首个小包和持续大批量的差异；这项小包速率不作为持续吞吐结果。
目标程序直接从只读程序盘运行，不安装、不创建登录项、不读取个人内容。
Book 诊断协调器先恢复键鼠，再上传测速盘；上传结束后释放文件端口，
不启动剪贴板组件。恢复正式复制粘贴前须退出测试并安全更换程序盘。

隔离测试：

```sh
python3 tests/test_bulk_probe.py
cargo test --offline --locked --manifest-path experiments/usb-throughput-probe/Cargo.toml
```

构建程序盘只生成新文件并验签，不启动应用或访问硬件：

```sh
python3 scripts/build_usb_probe.py --output build/usb-probe-NEW --module-cache build/shared-swift-cache-20261110
```

Book 测速工具接受 `--role host --all`、仅测本地收发的 `--role host --local`，或只读的 `--describe`。
`--raw-local` / `--raw-all` 是显式直接 Bulk 对照；线内窗口当前选择 `--raw-all`。
它通过正常 `USBInterfaceOpen` 仅打开身份、接口号和两条 Bulk 端点均匹配的文件数据接口，
不使用 seize、不重置设备、不改变 USB 配置，也不打开 HID 或控制接口。
驱动或其他客户端占用时直接报错，不强制接管、不回退到 TTY、不安装驱动。
只有诊断协调器已停用剪贴板并释放装载端口后才可运行；mini 的旧临时会话必须先退出。
`--packet-boundaries` 仅检查 512、1024、4096 字节本地回传；Book 的 `--peer-results` 只查询固件缓存的两项目标链路结果，不读取目标文件或任意地址。
mini 通过盘内「WiredKVM USB 测速」窗口启动目标测试。
工具严格匹配原型的角色、设备及文件接口，并取得独占锁；不打开键鼠接口。
文件端口以非阻塞系统 I/O 配合 `poll` 的就绪通知提供回压，不循环忙等。
普通握手、正文读写和收尾无进展超过 10 秒就报错；桥接首次会合最多等 70 秒，整次进程另受 240 秒上限约束。
正文按实际读到的字节立即检查，不用 `read_exact` 等满大块才发现短的中止报文。
桥接接收端的 READY 仅表示本端就绪。首批有效正文沿用 70 秒会合等待，
收到后才切换为 10 秒无进展超时；窗口会分别显示“等待另一端开始”和“正在传输”。
速率只在完整长度和完成报告通过后发布。发送计时包括等待设备完成确认；
接收计时从首个 read 返回至末个 read 返回，并从分子扣除首批已排队字节。
JSON 分别记录握手、首字节、正文 I/O、收尾确认与整体时间；512 字节单次读取
只作为边界检查通过，不报告持续速度。固件 READY 至完成的计时也可能包含会合等待。
当前恒定 A5 数据只能检查异常字节与计数，不能排除整块重复或重排。
此结果是该 CDC/TTY 实现的有效吞吐，仍不是芯片或 USB 总线的理论上限。
窗口会显示握手、正文、收尾和每 16 MiB 进度；超时退出明确显示未通过。
成功后窗口会在 3 秒后自动退出；关闭窗口或点“退出测速”会先结束测试子进程。
更新、推出程序盘或拔线前，须让旧应用完全退出。直接从盘运行的 Mach-O 仍可能
按需读取代码及常量；强制移除源卷后，旧进程可能因文件映射失效而 SIGBUS。
`python3 tests/test_usb_probe_ui.py` 在 Book 的自建隐藏窗口中验证自动退出和中途关闭，
不访问 USB、mini 或剪贴板；它不能代替目标机实际退出确认。
异常退出后的旧会话与缓冲可能仍存在，重测前需要干净的两端会话，不能把残留数据当成新测速回复。
不能用本机 socket、寄存器模型或离线 GB 测试代替实机速度及手势验收。

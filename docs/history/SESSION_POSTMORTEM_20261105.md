# WiredKVM 本会话复盘

记录日期：2026-11-05（Asia/Singapore）。本文件是历史记录，不是设备实时状态。

范围：本会话从 ESP32-S3 键鼠控制、剪贴板与安装盘，到 CH32 选型、源码恢复和本次 USB 重连。合并重复故障，保留不同错误；没有记录支持的原因不补写。证据索引见 `SESSION_EVIDENCE_20261105.json`。当前工作规则见项目根 `AGENTS.md`；可复用防错规则见 `../pitfalls.json`。

## 我应承担的主要错误

1. 我编写并运行了含不安全临时目录处理和递归清理的测试。随后项目大量文件丢失。这是最严重的工程事故；我对危险测试及后续处理负责。该代码是最强原因线索，但没有取得实际删除调用栈，不能伪造完整因果取证。
2. 我没有足够早地把产品目标与技术边界说清，反复在交换盘、脚本、配套组件之间推进，让用户多次纠正“像本机一样复制粘贴”的要求。
3. 跨机剪贴板曾影响两台机器内部的复制粘贴。这是隔离设计失败，不能作为实现跨机功能的代价。
4. 我在排查时反复要求双击、等待、翻线、换口和重置，没有始终保证每一步都有足够的诊断收益。
5. 我对测试证据的分层不够严格：图标、进程、一次通过、短时查询、构建成功，都不能代表用户功能和长期稳定性已通过。

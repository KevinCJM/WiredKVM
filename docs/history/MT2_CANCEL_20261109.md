# MT2 定位实验取消路径修订（2026-11-09）

目标仍为顺滑双指、四指操作和高速双向剪贴板；被控端不运行自定义程序，不用 macOS 共享。
上个目标回合仅重述控制恢复，没有推进这三项。本回合推进 MT2 原生设备路线的前置阻塞。

## 变更与依据

- 旧生成器 close/open EP82：SDK `usbd_endp_open` 显式设置 DATA0，可能丢失主机同步；取消时直接释放 busy 也可能让旧完成误归到新报告。
- 新窄 C 硬件边界 `single_port_abort.c`：NAK 写入强制保留 DONE/NAK_ACT 的 W0C 标志；RISC-V I/O fence 后检查 SIE 空闲、DONE 未挂起和 reset 未开始。任一未满足就保留 busy、旧 kind 和 DMA 缓冲，下一轮重试。已有 DONE 由普通 WCH 回调退役，不直接擦除全局 IRQ，不重开端点。
- 主循环的 abort_pending 跨轮保留；完成／reset 已清理旧所有权后，不得再取消新普通报告。调用有界，无 spin wait。
- Rust 核心新增 quiescing 状态位，主机 DISARM 等待逻辑也检查硬件状态；逻辑租约清零不能提前报告停止。新 ARM 和 prepare 在 quiescing 时被拒绝。
- 厂商手册 [CH32V407RM](https://www.wch.cn/downloads/CH32V407RM_PDF.html) V1.3，22.2.1.8、22.2.1.10、22.2.1.15、22.2.1.34：描述传输中断来源、SIE idle、自动 toggle 及 W0C DONE。读取的是厂商 PDF 的[公开镜像](https://ch32-riscv-ug.github.io/CH32V407/datasheet_en/CH32V407RM.PDF)，不是对其它 CH32 型号的寄存器类推。PDF 指纹在结果 JSON；镜像来源不等于厂商对本取消组合的保证。

## 离线结果与边界

- 48 项通过：profile 7、MT2 核心 18、探针 Rust 核心 7、Book 探针 16。
- 集成测试链接实际生成 main、实际 bridge/C glue/新取消边界及 Rust 状态机；USB API 为 mock。模型包含 W0C、自动 toggle、SIE busy、读写间完成、旧完成后紧接普通报告、reset settling、1,000 次取消／重新开始。
- 删除保留 DONE/NAK_ACT 的写法后，变异构建可编译但竞态回归失败。这表明测试可以抓住该错误，不证明实际电路时序。
- 新 `candidate-cancel-v2-20261109` 完成 RV32 构建，map 含硬件取消与 Rust quiescing 符号；反汇编核对保留标志写入和 I/O fence。构建资料与生产输入指纹在 profile.json；上一候选保留。
- `HARDWARE_EXECUTION_REVIEWED` 仍为 false；未访问或刷写设备，未重启当前控制，未在 mini 运行代码。新候选不是可交付固件。

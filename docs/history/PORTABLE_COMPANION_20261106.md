# 临时 Companion 候选与验证边界（2026-11-06）

## 用户确认的范围

用户允许 mini 临时运行配套程序，但不安装到 Applications、不注册后台或登录自启。目标仍是改善双指短滑、支持四指操作，以及快速有线双向文字、图片、文件和文件夹复制粘贴；不能破坏键鼠、自动边缘返回或任一机器的本地剪贴板。

DevSpace 仅用于开发时启动临时程序和查看 WiredKVM 日志，不是产品依赖。本次 mini 连接器两次 `open_workspace` 返回内部错误，未取得工作区，未在 mini 读取文件、执行命令或部署程序。用户随后询问是否要操作 mini 终端；已说明原计划是开发验证，不能把该问题当作连接恢复或安装许可。

## 本次实现

- 新增 `scripts/build_portable_companion.py`，构建 macOS 13+ 的 arm64/x86_64 通用程序，使用 `WK_PORTABLE` 编译条件。
- 编译时排除安装器、自复制、登录项和首次安装窗口。拒绝安装式启动参数以及无明确 CH32 文件通道的完整 host 模式。
- 便携版自动发现仅使用 CH32 文件 CDC Bulk 通道；不回退到旧 ESP32 HID 图片/文件正文路径。
- 没有设备时显示等待连接菜单及退出入口，避免打开后无界面、无图标。
- 便携版不自动推出来源安装盘，不自动写权限提示偏好；事件发送授权仍通过正常 macOS 提示处理。
- 便携版接收缓存和本地文件入口使用用户临时目录。临时运行不等于零磁盘写入：传输缓存、系统缓存和系统权限记录仍可能存在。
- 本次未刷写、暂停主芯片、重启当前控制器、发送真实输入，或访问通用剪贴板。

原文件备份与 SHA 清单位于 `results/portable-companion-20261106/before/` 和 `before-sha256.json`。

证据目录：`results/portable-companion-20261106/`。

4. 双向约 2.58 MB 的 PNG/TIFF、取消重试及本地复制隔离通过；文字/单文件双向、提前粘贴及本地复制优先通过。使用命名测试剪贴板与模拟文件入口，不访问通用剪贴板。

## 仍未完成

- mini 尚未运行该候选；双指短滑体感、四指动作、真实 Finder 进度和真实 USB 传输速度均未验收。
- 当前使用 macOS 已识别的手势事件转发，不是原始触点/手指数捕获。四指是否生效还取决于 Book 的手势识别与 mini 的事件权限，需实测。
- 当前可用 Book 控制链仍为 input-only，跨机剪贴板未启用。不能把离线通过当成当前两台机器已经支持复制粘贴。
- 当前源代码支持文字、规范化图片及单个普通文件；多文件和文件夹仍未实现。图片正文走 Bulk，实际完成时间未测。
- Petros 当前固件的 `setup_flash_none.c` 不提供安装介质。线内交付此临时程序尚未实现；不能声称当前插线即可运行。
- 当前控制固件仍为已验证的 `53b4b741a9212ffb3c8a89dcb9aef282b4b3643bbf2a11696f8c23e5e97a6e70`，没有更换为 MT2 实验版。MT2 026c 的取消/端点状态问题仍未关闭，不部署。
